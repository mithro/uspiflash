A generator of tiny, single-file C libraries that detect SPI flash chips (JEDEC read-id, legacy ids, SFDP) and report their size, geometry, voltages, capabilities and supported commands, built from the spiflash database. Two packages:

  • python3-uspiflash provides the uspiflash command. It is architecture all (pure Python), so it installs on any Debian or Raspberry Pi OS machine; it depends on python3-spiflash from spiflash's own apt repository.
  • uspiflash-linux identifies the SPI flash chip on a Linux spidev device (/dev/spidevX.Y) and describes it as spiflash id does. It is a small C program with no dependency beyond libc, built for amd64, i386, arm64, armhf and riscv64 (riscv64 from trixie on).
