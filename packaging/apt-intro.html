A generator of tiny, single-file C libraries that detect SPI flash chips (JEDEC read-id, legacy ids, SFDP) and report their size, geometry, voltages, capabilities and supported commands, built from the spiflash database. Install python3-uspiflash, which provides the uspiflash command. The package is architecture all (pure Python), so it installs on any Debian or Raspberry Pi OS machine; it depends on python3-spiflash from spiflash's own apt repository.
