## Pre-flight corrections (2026-09-29)

This plan was written before Parts C and D existed. The pre-flight check
compiled its C against a freshly generated header (gcc 14 and clang 19,
`harness.CFLAGS` including `-Wshadow`, dynamic, `-static`, and with
Debian's hardening flags), ran its tests against the oracle, and read
QEMU's and Debian's sources. The code below is the corrected, verified
version. The rulings (the controller confirms them):

- **R1. The tool's header has every chip type** (`--type nor --type nand`),
  though `generate` defaults to SPI NOR (spec amendment 12). The
  maintainer's NOR-first decision is about the default for size-bound
  targets; the tool has no size budget and promises `spiflash id`'s
  output, which covers 127 NAND chips. A NOR-only build tells a user with
  a SPI NAND chip (W25N01GV, checked) "no chip in the database answers",
  and `id c8b148` prints nothing. The cost is about 25 KB of binary. Every
  place that generates the tool's header (Makefile, `debian/rules`, tests,
  the QEMU image) says `--type nor --type nand`.
- **R2. QEMU runs inside the container**, locally and in CI.
  `tools/qemu/Dockerfile` installs `qemu-system-misc`, so the host needs
  only docker, not `qemu-system-riscv64` (this machine has none; the
  trixie image's QEMU 10.0.13 has `sifive_u` and OpenSBI, checked).
  `tests/test_qemu.py` skips unless `USPIFLASH_QEMU=1` and docker is on
  `PATH`. Docker containers run outside the caller's systemd scope, so
  `run.py` passes `uspiflash.sandbox.current_limits()` to `docker run` as
  `--memory`/`--cpus`/`--pids-limit`. A developer runs the test through the
  sandbox as usual.
- **R3. The guest never loads `spi-nor`.** Debian trixie's kernel has
  `CONFIG_SPI_SIFIVE=m`, `CONFIG_MTD_SPI_NOR=m` and `CONFIG_SPI_SPIDEV=y`.
  Without `spi-nor` loaded, the flash stays unbound, and `init` binds it
  to spidev through `driver_override`. There is no rebinding.
- **R4. The .deb ships a dynamically linked tool** (the old plan's call,
  kept). Spec §2 says "static tool", so Task 17 records it as spec
  amendment 13, not only in `RELEASING.md`. The Makefile still builds
  static by default.
- **R5. `deb.yml` keeps its own `build-deb` job**, so the job names and the
  custom install test (gcc in the container) stay. It does per
  architecture what apt-repo-action's reusable workflow does
  (`scripts/build-matrix.py` at `3149690`):
  - a runner per architecture;
  - `arch-all` on the amd64 job only, so each suite's `_all.deb` is built
    exactly once;
  - the install test on amd64 only.

  The old plan argued that identical `_all.deb`s may overwrite each other.
  That is superseded by the action's `arch-all` input. The action passes no
  `DEB_BUILD_OPTIONS` into its container, so `debian/rules` itself skips
  the tests on riscv64, the one architecture GitHub's runners always
  emulate (packaging.md allows `nocheck` there).
- **R6. `--version`** prints `uspiflash-linux: <uspiflash --version>`. The
  builder passes it as `-DUSPIFLASH_LINUX_VERSION`, since the header
  defines no version macro.
- **R7. The tool waits tRES1 after RES.** It defines `USF_DELAY_US` as a
  `nanosleep` before including the header. The old code had no wait, so a
  chip in deep power-down could miss RDID.
- **R8. `--json --sfdp` is a usage error** (the SFDP lines are text), and
  `id HEX` rejects anything but hex byte pairs (spaces allowed, as
  spiflash takes them).
- **R9. The QEMU image's Debian packages come from snapshot.debian.org**
  at `uspiflash.ledger.SNAPSHOT`, on the ledger's pinned `IMAGE`. The
  pinned kernel then stays fetchable after the next point release, as the
  size ledger's tools do.

### Task 16: `uspiflash-linux`, a spidev tool that prints what `spiflash id` prints

**Files:**
- Create: `examples/linux/uspiflash-linux.c`, `examples/linux/Makefile`,
  `examples/linux/README.md`, `tests/linux/fake_spidev.c`,
  `tests/test_linux_tool.py`

**Interfaces:**
- Consumes: `usf_probe`, `usf_print`, `usf_print_json`, `usf_sfdp_read`,
  `usf_lookup`, `USF_LOOKUP_MAX`, `USF_DELAY_US` from a header generated with
  `--level full --type nor --type nand --with sfdp --with sfdp_dumps --with datasheet --with datasheets --with records --with provenance`.
  That is every chip type (R1) and every extra that changes the output
  (`jep106` only adds `usf_jep106`). The tool has no size budget, so its
  output is byte-identical to `spiflash id`, datasheet lines, `sfdp:`
  lines, records and the JSON `sfdp` list included: `full` has the `sfdp:`
  lines, `sfdp_dumps` adds the JSON list and `sfdp` adds `usf_sfdp_read`.
  Also consumes `tests/c/simchip.h` (its `sim_parse` / `sim_xfer`, a NOR
  chip's shifted `9f` answers, `sfdp=`), and `tests/harness.py`'s `CFLAGS`
  and `parity`.
- Produces:
  - `uspiflash-linux [-D DEVICE] [-s HZ] [--json | --sfdp] [--opcodes]`:
    probes `DEVICE` (default `/dev/spidev0.0`) at `HZ` (default 1000000).
    Exit codes:
    - 0: found and printed;
    - 1: a chip answered but isn't in the database (prints its family and
      the bytes read);
    - 2: nothing answered, or a usage/device error.
  - `uspiflash-linux id HEX [--method FAMILY] [--json] [--opcodes]`: offline
    lookup, byte-identical to `spiflash id HEX [--method F] [--opcodes|--json]`,
    with spiflash's exit codes (0 found, 1 none), and 2 for bad arguments.
  - `uspiflash-linux --version`: `uspiflash-linux: uspiflash X (spiflash Y)`,
    the generator that made its header (R6).

Each transaction is one `SPI_IOC_MESSAGE(2)` with chip select held: a TX
transfer of `txlen` bytes, then an RX transfer of `rxlen` bytes. This
matches the library's half-duplex model exactly, and lets the fake device
see where the command ends.

- [ ] **Step 1: The fake spidev (test support)**

`tests/linux/fake_spidev.c`, an `LD_PRELOAD` shared object. It is compiled
with `harness.CFLAGS`; `dlsym`'s result is copied into the function pointer,
because `-Wpedantic` rejects the cast.

```c
/* LD_PRELOAD shim: opening $FAKE_SPIDEV gives a simulated SPI flash
 * ($FAKE_SPIDEV_SPEC, tests/c/simchip.h's spec) and SPI_IOC_MESSAGE(2)
 * transactions are answered by it; with $FAKE_SPIDEV_LOG set, each is
 * logged to stderr. Test support only. */
#define _GNU_SOURCE
#include <dlfcn.h>
#include <fcntl.h>
#include <stdarg.h>
#include <stdint.h>
#include <string.h>
#include <sys/ioctl.h>
#include <linux/spi/spidev.h>

#include "simchip.h"

static struct sim sim;
static int fake_fd = -1;

typedef int (*open_fn)(const char *, int, ...);
typedef int (*ioctl_fn)(int, unsigned long, ...);

/* The next definition of `name`. ISO C has no conversion from dlsym's
 * object pointer to a function pointer, so the bytes are copied (POSIX
 * guarantees they are the same). */
static void next_symbol(const char *name, void *fn, size_t size)
{
    void *p = dlsym(RTLD_NEXT, name);
    memcpy(fn, &p, size);
}

static int fake_open(const char *path, int flags, mode_t mode, const char *real_name)
{
    open_fn real;
    const char *fake = getenv("FAKE_SPIDEV");
    next_symbol(real_name, &real, sizeof real);
    if (fake && strcmp(path, fake) == 0) {
        const char *spec = getenv("FAKE_SPIDEV_SPEC");
        sim.log = getenv("FAKE_SPIDEV_LOG") ? stderr : NULL;
        sim_parse(&sim, spec ? spec : "");
        fake_fd = real("/dev/null", O_RDWR);
        return fake_fd;
    }
    return real(path, flags, mode);
}

int open(const char *path, int flags, ...)
{
    mode_t mode = 0;
    if (flags & O_CREAT) {
        va_list ap;
        va_start(ap, flags);
        mode = (mode_t)va_arg(ap, int);
        va_end(ap);
    }
    return fake_open(path, flags, mode, "open");
}

int open64(const char *path, int flags, ...)
{
    mode_t mode = 0;
    if (flags & O_CREAT) {
        va_list ap;
        va_start(ap, flags);
        mode = (mode_t)va_arg(ap, int);
        va_end(ap);
    }
    return fake_open(path, flags, mode, "open64");
}

int ioctl(int fd, unsigned long request, ...)
{
    ioctl_fn real;
    va_list ap;
    void *arg;
    va_start(ap, request);
    arg = va_arg(ap, void *);
    va_end(ap);
    if (fd < 0 || fd != fake_fd) {
        next_symbol("ioctl", &real, sizeof real);
        return real(fd, request, arg);
    }
    if (request == SPI_IOC_MESSAGE(2)) {
        struct spi_ioc_transfer *t = (struct spi_ioc_transfer *)arg;
        sim_xfer(&sim, (const uint8_t *)(uintptr_t)t[0].tx_buf, (uint8_t)t[0].len,
                 (uint8_t *)(uintptr_t)t[1].rx_buf, (uint8_t)t[1].len);
        return (int)(t[0].len + t[1].len);
    }
    return 0;  /* mode, bits per word and speed settings all "succeed" */
}
```

```c
/*
 * uspiflash-linux: identify the SPI flash chip on a Linux spidev device and
 * describe it the way `spiflash id --opcodes` does, or look an id up offline.
 *
 *   uspiflash-linux [-D /dev/spidevB.C] [-s HZ] [--json] [--opcodes] [--sfdp]
 *   uspiflash-linux id HEX [--method jedec|rems|res1|res2|at25f|st95] [--json] [--opcodes]
 *   uspiflash-linux --version
 *
 * Built against a header made by `uspiflash generate --level full --type nor
 * --type nand` with every extra that changes the output (see the Makefile):
 * every chip type, as `spiflash id` knows them (generate alone keeps only
 * SPI NOR). Each library transaction is one SPI_IOC_MESSAGE(2): the command
 * bytes, then the answer, chip select held.
 */
#include <ctype.h>
#include <fcntl.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/ioctl.h>
#include <time.h>
#include <unistd.h>
#include <linux/spi/spidev.h>

/* The builder passes the generator's `uspiflash --version` line. */
#ifndef USPIFLASH_LINUX_VERSION
#define USPIFLASH_LINUX_VERSION "unknown"
#endif

/* The probe's wake-up wait after RES (tRES1): see USF_DELAY_US in the header. */
static void delay_us(unsigned us)
{
    struct timespec ts;
    ts.tv_sec = 0;
    ts.tv_nsec = (long)us * 1000L;
    nanosleep(&ts, NULL);
}
#define USF_DELAY_US(us) delay_us(us)

#define USF_IMPLEMENTATION
#include "uspiflash.h"

/* spiflash's --method names, in USF_FAMILY_* order. */
static const char *const families[] = {"jedec", "rems", "res1", "res2", "at25f", "st95"};

struct dev {
    int fd;
    uint32_t hz;
};

static void xfer(void *ctx, const uint8_t *tx, uint8_t txlen, uint8_t *rx, uint8_t rxlen)
{
    struct dev *d = (struct dev *)ctx;
    struct spi_ioc_transfer t[2];
    memset(t, 0, sizeof t);
    t[0].tx_buf = (uintptr_t)tx;
    t[0].len = txlen;
    t[0].speed_hz = d->hz;
    t[0].bits_per_word = 8;
    t[1].rx_buf = (uintptr_t)rx;
    t[1].len = rxlen;
    t[1].speed_hz = d->hz;
    t[1].bits_per_word = 8;
    if (ioctl(d->fd, SPI_IOC_MESSAGE(2), t) < 0) {
        perror("uspiflash-linux: SPI_IOC_MESSAGE");
        exit(2);
    }
}

static void put(void *ctx, char ch)
{
    (void)ctx;
    putchar(ch);
}

static int family_code(const char *name)
{
    int i;
    for (i = 0; i < 6; i++)
        if (strcmp(name, families[i]) == 0)
            return i;
    return -1;
}

static int nibble(char ch)
{
    return isdigit((unsigned char)ch) ? ch - '0' : tolower((unsigned char)ch) - 'a' + 10;
}

/* Hex digits, optionally separated by spaces (as spiflash takes them), into
 * data; the byte count, or -1 if `s` is not that or is longer than max. */
static int parse_hex(const char *s, uint8_t *data, unsigned max)
{
    unsigned n = 0;
    while (*s) {
        if (*s == ' ') {
            s++;
            continue;
        }
        if (!isxdigit((unsigned char)s[0]) || !isxdigit((unsigned char)s[1]) || n == max)
            return -1;
        data[n++] = (uint8_t)(nibble(s[0]) << 4 | nibble(s[1]));
        s += 2;
    }
    return (int)n;
}

static void hex(const uint8_t *b, unsigned n)
{
    unsigned i;
    for (i = 0; i < n; i++)
        printf("%02x", b[i]);
}

/* The chip's own SFDP, as tests/c/harness.c's S command prints it
 * (uspiflash.oracle.sfdp_fields()'s format). */
static void print_sfdp(const usf_sfdp *f)
{
    static const char *const modes[] = {"1-1-2", "1-2-2", "1-1-4", "1-4-4", "2-2-2", "4-4-4"};
    unsigned k;
    printf("sfdp=%u.%u dwords=%u addr=%u erase4k=0x%02x dtr=%u size=%lu page=%u", f->rev_major,
           f->rev_minor, f->dwords, f->address_bytes, f->erase_4k_opcode, f->flags & USF_SFDP_DTR,
           (unsigned long)f->size, f->page_size);
    if (f->quad_enable == 0xFF)
        printf(" qe=none");
    else
        printf(" qe=%u", f->quad_enable);
    printf(" en4b=0x%02x ex4b=0x%02x\nerase", f->enter_4b, f->exit_4b);
    for (k = 0; k < 4; k++)
        if (f->erase_log2[k])
            printf(" %u:%u:0x%02x", k + 1, f->erase_log2[k], f->erase_opcode[k]);
    printf("\nread");
    for (k = 0; k < 6; k++)
        if (f->reads >> k & 1)
            printf(" %s:0x%02x:%u+%u", modes[k], f->read_opcode[k], f->read_clocks[k] >> 5,
                   f->read_clocks[k] & 31u);
    putchar('\n');
}

static int usage(void)
{
    fputs("usage: uspiflash-linux [-D DEVICE] [-s HZ] [--json] [--opcodes] [--sfdp]\n"
          "       uspiflash-linux id HEX [--method FAMILY] [--json] [--opcodes]\n"
          "       uspiflash-linux --version\n",
          stderr);
    return 2;
}

int main(int argc, char **argv)
{
    const char *device = "/dev/spidev0.0", *method = "jedec", *idhex = NULL;
    int json = 0, opcodes = 0, want_sfdp = 0, i;
    uint32_t hz = 1000000;

    for (i = 1; i < argc; i++) {
        if (!strcmp(argv[i], "-D") && i + 1 < argc)
            device = argv[++i];
        else if (!strcmp(argv[i], "-s") && i + 1 < argc)
            hz = (uint32_t)strtoul(argv[++i], NULL, 0);
        else if (!strcmp(argv[i], "--method") && i + 1 < argc)
            method = argv[++i];
        else if (!strcmp(argv[i], "--json"))
            json = 1;
        else if (!strcmp(argv[i], "--opcodes"))
            opcodes = 1;
        else if (!strcmp(argv[i], "--sfdp"))
            want_sfdp = 1;
        else if (!strcmp(argv[i], "--version")) {
            printf("uspiflash-linux: %s\n", USPIFLASH_LINUX_VERSION);
            return 0;
        } else if (!strcmp(argv[i], "id") && i + 1 < argc)
            idhex = argv[++i];
        else
            return usage();
    }
    if (json && want_sfdp)                /* the SFDP lines are text, not JSON */
        return usage();

    if (idhex) {                         /* offline, like `spiflash id` */
        uint8_t data[64];
        usf_chip chips[USF_LOOKUP_MAX];
        uint8_t found;
        int fam = family_code(method), n = parse_hex(idhex, data, sizeof data);
        if (fam < 0 || n < 0)
            return usage();
        found = usf_lookup((uint8_t)fam, data, (uint8_t)n, chips);
        if (json)
            usf_print_json(chips, found, put, NULL);
        else
            usf_print(chips, found, opcodes ? USF_PRINT_OPCODES : 0, put, NULL);
        return found ? 0 : 1;
    }

    {                                     /* probe a real device */
        struct dev d;
        usf_bus bus;
        usf_probe_result r;
        uint8_t mode = SPI_MODE_0, bits = 8;
        d.fd = open(device, O_RDWR);
        d.hz = hz;
        if (d.fd < 0) {
            perror(device);
            return 2;
        }
        if (ioctl(d.fd, SPI_IOC_WR_MODE, &mode) < 0 || ioctl(d.fd, SPI_IOC_WR_BITS_PER_WORD, &bits) < 0
            || ioctl(d.fd, SPI_IOC_WR_MAX_SPEED_HZ, &hz) < 0) {
            perror("uspiflash-linux: configuring the spidev device");
            return 2;
        }
        bus.xfer = xfer;
        bus.ctx = &d;
        usf_probe(&bus, &r);
        if (r.count) {
            if (json)
                usf_print_json(r.chip, r.count, put, NULL);
            else
                usf_print(r.chip, r.count, opcodes ? USF_PRINT_OPCODES : 0, put, NULL);
        } else if (r.len) {
            printf("no chip in the database answers %s ", families[r.family]);
            hex(r.id, r.len);
            putchar('\n');
        } else {
            printf("no answer from the chip (the bus reads all 0x00 or all 0xff)\n");
        }
        if (want_sfdp) {
            usf_sfdp s;
            if (usf_sfdp_read(&bus, &s))
                print_sfdp(&s);
            else
                printf("sfdp=none\n");
        }
        close(d.fd);
        return r.count ? 0 : r.len ? 1 : 2;
    }
}
```

1. At the QEMU commit spiflash's dumps come from (`81ce3a87`, in

   byte (`:1573-1580`), as the library sends.
2. The emulated chip's RDID answer (`m25p80.c:1419-1431`) is the 3 id
   bytes, then zeros up to 6 bytes. The flash then goes idle, and each
   further byte clocked (spidev sends `0x00`) decodes as a NOP and reads

   so the probe goes on to RDID.

     `/usr/lib/modules`;

     magic), which `-kernel` takes.
4. The trixie image's `qemu-system-misc` (QEMU 10.0.13) has `sifive_u`, and
   OpenSBI firmware (`opensbi-riscv64-generic-fw_dynamic.bin`) for
